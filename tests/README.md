# Тесты плеера

Это автоматическая проверка плеера. Страница открывает настоящий плеер, сама нажимает кнопки, перематывает видео, включает блюр, грузит субтитры и смотрит, что получилось. Если что-то сломалось, вы увидите красную строку с объяснением

## Как запустить

1. Нужен [Node.js](https://nodejs.org). Больше ничего ставить не надо
2. Откройте терминал в папке проекта и выполните:

```bash
node tests/serve.js 8000
```

3. Откройте в Chrome `http://localhost:8000/tests/` и нажмите «Запустить»

Полный прогон идёт около 20 минут. Слева можно отметить только нужные наборы, тогда быстрее

## На что обратить внимание

- **Окно браузера должно быть на виду.** Если свернуть его или закрыть другим окном, Chrome замораживает анимации и замедляет таймеры, и тесты про время начнут падать. Плеер тут ни при чём. Стенд сам предупредит жёлтой плашкой, если окно перекрыто
- **Двойным кликом по файлу не откроется.** Тестам нужен именно сервер, потому что перемотка в видео требует от сервера умения отдавать файл кусками. Обычный `python -m http.server` так не умеет, поэтому в папке свой
- **Набор «панель звука» может оказаться пропущенным.** Ему нужен второй сервер без CORS, чтобы проверить, как плеер ведёт себя с чужим источником. Если хотите его запустить, во втором терминале:

```bash
node tests/serve.js 8001 --no-cors
```

- **Звука не будет.** Все ролики беззвучные, тесты проверяют звук по цифрам, а не ушами
- **Один тест отдельно:** добавьте к адресу `?only=часть названия`, например `http://localhost:8000/tests/?only=громкость`

## Что в папке

| | |
|---|---|
| `index.html` | сам стенд и все тесты |
| `serve.js` | сервер для запуска |
| `fixtures/` | ролики и файлы, на которых тесты гоняют плеер |

## Если хотите добавить тест

Все тесты в `index.html`, в функции `runAll`. Тест выглядит так:

```js
suite('громкость');
await test('стрелка вверх прибавляет громкость', нужноВидео(async () => {
  setVal('volume-range', 0.5);
  key('ArrowUp');
  assertClose(video().volume, 0.52, 0.001, 'громкость не выросла');
}));
```

`suite` открывает набор, `test` описывает один сценарий. Перед каждым тестом плеер приводится к чистому состоянию: хранилище пустое, панели закрыты, ролик открыт и стоит на паузе. `нужноВидео` значит «этому тесту нужен открытый ролик», есть такие же обёртки для сериалов и HLS, они пропускают тест, если нужных файлов нет. Проверяйте то, что видит зритель: позицию, текст на экране, что записалось в хранилище

Новый набор появится в списке слева сам. Чтобы он лёг в свою группу, добавьте его имя в список `GROUPS` в начале файла
