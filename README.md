## Функции плеера

- Открывает локальные `mp4`, `webm`, `mov` файлы и целые папки с видео
- Поддерживает ссылки на `.m3u8` (HLS-плейлисты)
- Собирает видео из папки в плейлист с естественной сортировкой серий
- Сохраняет прогресс просмотра для каждого файла и позволяет продолжить просмотр позже (Chromium)
- Поддерживает субтитры `.srt` с настройкой их внешнего вида
- Показывает на видео оверлей с названием и таймингом, который можно перемещать в любой угол
- Размывает видео в заданных интервалах времени
- Позволяет зеркалить видео, менять скорость, яркость и масштаб
- Включает компрессию и усиление звука
- Поддерживает полноэкранный режим
- Горячие клавиши для управления плеером

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Space` | Воспроизвести / Пауза |
| `←` `→` | Перемотка на 5 секунд |
| `Shift` + `←` `→` | Перемотка на 1 секунду |
| `↑` `↓` | Изменить громкость |
| `M` | Выключить / Включить звук |
| `F` | Полный экран |

## Запуск

Можно просто открыть **[живое демо](https://leenmosy.github.io/local-player/)** – ставить ничего не надо, файлы никуда не загружаются, всё работает локально в вашем браузере

Или запустить у себя:

1. Клонируете репозиторий (или просто скачиваете)
2. Открываете `index.html` в браузере (только Chromium)
3. Выбираете файл, папку с файлами или вставляете ссылку на `.m3u8`

Интернет нужен только чтобы один раз подтянуть [hls.js](https://github.com/video-dev/hls.js) с CDN ну и для самих HLS-потоков, они по определению из сети

## Работа с HLS-ссылками

Для удобного поиска и копирования m3u8/HLS-ссылок можно использовать расширение **[FetchV](https://fetchv.net/ru)**. Оно находит ссылки на видео, чтобы их можно было быстро скопировать и вставить в плеер. Также расширение позволяет удобно загружать видео

- Этот инструмент предназначен только для видео, соответствующих техническим стандартам; он не подходит для видео, использующих нестандартные технологии воспроизведения. Не предоставляет специальной настройки для конкретных веб-сайтов
- Не поддерживает видео, защищенные шифрованием. Мы не несем ответственности за любые медиафайлы, которые вы загружаете; рекомендуется проверять авторские права медиа перед загрузкой
- Хотя этот инструмент адаптирован для популярных веб-видео, он не гарантирует абсолютный успех загрузки в пределах поддерживаемых форматов. Если он не работает для вас, приносим извинения и рекомендуем попробовать другие инструменты в качестве альтернативы

## Ограничения

- Только десктоп или ноутбук. На сенсорных экранах заглушка вместо интерфейса
- Не все HLS-ссылки одинаково хорошо воспроизводятся. Зависит от кодека, шифрования потока и настроек CORS на стороне сервера, который отдаёт `.m3u8`
- Открытие файла без повторного диалога («Продолжить с того же места») работает в браузерах на Chromium, в Firefox и Safari нет поддержки File System Access API
